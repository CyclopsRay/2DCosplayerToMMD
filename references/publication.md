# Public release boundaries

Read this only when public sharing/repository packaging is part of the user's request.
Complete a concrete, reviewable repository before publication. Reuse explicit publication
authorization already given; do not ask again merely because GitHub is external.

Separate code from private runs from the start. Ignore motions, archives, source models,
Blender scenes/backups, exported meshes, textures, audio, credentials, provider responses,
logs and signed download URLs. A blend, FBX or JSON with baked motion still redistributes
the motion. Do not upload extracted animation curves or third-party reference model data.

A small, authorized rendered demo and reduced input/reference images can illustrate the
result. Credit the image, generation service, motion author, choreography and song source.
Keep source asset links rather than rehosting restricted downloads/passwords. Check actual
terms and existing permissions; do not infer that a code license covers demo media.
The reference motion terms are at https://privatter.net/p/7867947 and the download page
is https://bowlroll.net/file/96407. These are examples, not a default motion for every task.

CosMMD's publishing guard scans staged blobs and reachable history, rejects common asset
formats/content signatures and credential patterns, and requires hashes/provenance for
approved presentation media. Review the actual staged list as well. Run it before the
first push; CI after publication cannot prevent the initial disclosure. A .gitignore
change does not remove a secret already committed. Do not publish a contaminated history.

Marketing should lead with a true before/after. State whether a showcase reused a Studio
model, needed human/agent calibration, or did not exercise a newly written API client.
Never claim universal success, zero manual work, exact identity preservation, physical
cloth simulation or native PMX compatibility without evidence. GIFs should show actual
rendered motion with honest duration; do not edit away defective poses to simulate success.
